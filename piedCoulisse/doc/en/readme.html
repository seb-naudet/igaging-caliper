igaging-caliper: talking caliper

NVDA add-on that makes NVDA speak the measurements of an iGaging Bluetooth caliper, without the digits being typed into the open window. Each measurement is also added to a text file.

Supported device

iGaging Bluetooth caliper, which shows up in Windows as "Bluetooth Keyboard". It behaves like a keyboard: each time it sends, it types the F24 key, a space, then the measurement. The add-on recognizes the F24 key; a device that does not send F24 will not be recognized.

Checked with model 100-700-B06 on Windows 11.

Installation

  1. Open the file igaging-caliper.nvda-addon (press Enter on it in File Explorer), confirm the installation, then restart NVDA.
  2. Pair the caliper in Windows: Settings, Bluetooth & devices, Add device, Bluetooth, choose "Bluetooth Keyboard".

Usage

Press the DATA button of the caliper: NVDA says for example "21.99 millimeters". Nothing is typed into the active window, whether you are in an edit field or in browse mode on a web page.

If the measurement does not arrive

  • The caliper's display is off (ON/OFF button): the caliper no longer measures and DATA sends nothing, but it may stay connected over Bluetooth, so NVDA does not say "disconnected". Press ON/OFF: this button turns the display back on and restarts measuring. Then wait a few seconds before pressing DATA; iGaging recommends 10 seconds.
  • NVDA said "disconnected": with the display on, hold DATA for about 5 seconds to reconnect, then wait a few seconds before measuring. The caliper never reconnects by itself: even a one-minute break (computer Bluetooth turned off, sleep mode, caliper taken out of range) requires this gesture.
  • The caliper turns off or disconnects by itself: the battery is getting weak and needs replacing.

Turning off, Bluetooth and battery

The caliper does not turn off by itself. iGaging states that it stops after 5 minutes without use, but on the tested model the display stays on and measurements are still sent after 2 hours without touching it: as long as it stays connected, it stays ready. This 5-minute stop probably only applies to Bluetooth when no device takes the connection: if NVDA does not say "connected" within a few minutes, hold DATA again for about 5 seconds. Spontaneous shutdowns or disconnections only appear when the battery gets weak.

To turn it off completely and save the battery:

  1. Press ON/OFF to turn the display off.
  2. Briefly press DATA: no measurement should be spoken, which confirms that the caliper is off.
  3. Hold DATA for about 5 seconds: Bluetooth turns off and NVDA says "Caliper disconnected".

To start again: press ON/OFF, then hold DATA for about 5 seconds to reconnect. After changing the battery, check the zero with the jaws closed; if needed, briefly press ORIGIN.

The battery level can be reported by a command that has no default shortcut: to use it, assign a gesture in Preferences, Input gestures, "Caliper" category, "Report the caliper battery level". While the caliper is connected, the level is up to date, for example "Caliper battery 96 percent". When it is disconnected, NVDA gives the last known level: "Caliper disconnected, last known battery level 96 percent".

Settings

NVDA menu, Preferences, Settings, "Caliper" category:

  • Announce when the caliper connects or disconnects (checked by default): NVDA says "Caliper connected" or "Caliper disconnected", about 2 seconds after the change. The caliper is recognized by its Bluetooth name, "Bluetooth Keyboard": if a real Bluetooth Low Energy keyboard has the same name, the announcement will apply to it too; in that case, uncheck this box.
  • Save measurements to a file (measurements.txt, checked by default): one line per measurement, tab-separated columns: date and time, value (decimal point), unit, "caliper". The file opens in a spreadsheet.
  • Measurements file folder: by default the "Caliper measurements" folder in Documents (created at the first measurement). The Browse button lets you choose another one.
  • Copy each measurement to the clipboard (unchecked by default): the value (for example 21.99) is ready to paste with Control+V.
  • Log received keys (unchecked by default): for troubleshooting, records every key received in a "logs" subfolder.

F24 key

The gesture is in Preferences, Input gestures, "Caliper" category. Do not remove it: without it, the measurement is typed into the active window again.

Languages

The add-on follows NVDA's language: English, French, German or Spanish (English for other languages).
